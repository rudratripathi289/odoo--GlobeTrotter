# Project Name (Odoo Hackathon)

Welcome to the project! This repository contains both the frontend and backend applications.

## Directory Structure

- `/frontend` - React application (Vite, Tailwind v4, TanStack Router)
- `/backend` - Node.js server (Express, Prisma, PostgreSQL/NeonDB)
- `/docs` - Documentation for the project

## Getting Started

### Backend
1. Navigate to the `backend` folder: `cd backend`
2. Install dependencies: `npm install`
3. Set up your `.env` file (see `backend/.env.example`)
4. Run the development server: `npm run dev`

### Frontend
1. Navigate to the `frontend` folder: `cd frontend`
2. Install dependencies: `npm install`
3. Run the Vite development server: `npm run dev`
